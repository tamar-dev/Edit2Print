# Chrome Web Store listing

**Name:** Just Print Selection

**Short description:** Print selected text and images, or save just part of a webpage as PDF.

**Detailed description (English):**
Print only what you need. Highlight a portion of a webpage, right-click and choose “Print selection” to print selected text, images and basic formatting. Right-click a single image to print it on its own. Chrome's print dialog also lets you choose “Save as PDF” — a handy way to save only part of a long page instead of the entire page.

Features: selection printing, single-image printing, mixed text and images, automatic image size limits for paper, Hebrew/RTL support, and PDF export using Chrome's built-in print dialog. No account or developer-operated server required.

Note: Some websites, complex layouts, embedded frames and protected pages may not print exactly as shown.

**Suggested category:** Productivity

**Single purpose:** Print or save selected webpage content through Chrome's print dialog.

**Permission justification:** `contextMenus` adds the command; `activeTab` and `scripting` access selected content only after a user click; `storage` temporarily passes the selected markup to the preview tab.

**Data-use disclosure:** No developer-operated collection or sale of user data. The selected content is temporarily held locally, then removed on preview load. Images can be fetched from their original hosts.
